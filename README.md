# تسيير المحل — gestion-frigo

تطبيق أندرويد مكتوب بـ **Flutter** لتسيير محل بيع المواد الغذائية، مع قراءة **الباركود** بكاميرا الهاتف أو بقارئ باركود خارجي (USB / بلوتوث).
الواجهة بالعربية (من اليمين إلى اليسار) والعملة بالدينار الجزائري (دج). جميع البيانات محفوظة محليا على الهاتف (SQLite) ولا يحتاج التطبيق إلى الإنترنت.

## الوظائف

| الشاشة | ما تفعله |
|---|---|
| **الرئيسية** | مبيعات وربح اليوم، عدد العمليات، قيمة المخزون، تنبيهات المخزون الناقص والمنتجات القريبة من انتهاء الصلاحية، وأزرار سريعة |
| **البيع** | مسح الباركود بالكاميرا بشكل متواصل لإضافة المنتجات للسلة، أو إدخال الباركود بقارئ خارجي، أو البحث بالاسم؛ تعديل الكميات، حساب الباقي للزبون، وتسجيل البيع مع خصم الكمية من المخزون |
| **المنتجات** | إضافة / تعديل / حذف المنتجات (الاسم، الباركود، الصنف، الوحدة، سعر الشراء والبيع، الكمية، حد التنبيه، تاريخ الصلاحية)، بحث وتصفية حسب الصنف أو المخزون الناقص أو الصلاحية |
| **المبيعات** | سجل المبيعات لليوم / 7 أيام / الشهر / الكل مع المجموع والربح، تفاصيل كل عملية، وإلغاء عملية بيع مع إرجاع السلع إلى المخزون |

### خصائص الباركود
- مسح بالكاميرا (EAN-13، EAN-8، UPC، Code128، Code39، QR ...) مع الفلاش وتبديل الكاميرا وإدخال يدوي.
- **وضع البيع المتواصل**: تبقى الكاميرا مفتوحة وتضيف كل منتج يُمسح إلى السلة.
- **إدخال السلع بالباركود**: امسح المنتج ثم أدخل الكمية المستلمة من المورّد؛ وإذا كان الباركود غير مسجل يقترح التطبيق إضافته.
- **التحقق من السعر**: امسح أي منتج لعرض سعره ومخزونه.
- **توليد باركود داخلي** (EAN-13 يبدأ بـ 2) للمنتجات التي لا تملك باركود (الخبز، السلع بالوزن...).
- منع تكرار نفس الباركود لمنتجين.

## التشغيل

المتطلبات: Flutter 3.35 أو أحدث، و Android SDK.

```bash
flutter pub get
flutter run            # على هاتف متصل أو محاكي
flutter build apk      # ملف APK في build/app/outputs/flutter-apk/
flutter test           # الاختبارات
```

كما يبني GitHub Actions ملف APK تلقائيا عند كل push (تبويب **Actions** ← آخر تشغيل ← `gestion-magasin-apk`).

## بنية المشروع

```
lib/
├── main.dart                   # نقطة الانطلاق، اللغة العربية والثيم
├── data/store_database.dart    # قاعدة بيانات SQLite (المنتجات، المبيعات)
├── models/                     # Product, Sale, SaleItem, CartItem
├── providers/                  # StoreProvider (المنتجات والإحصائيات)، CartProvider (السلة)
├── screens/                    # الرئيسية، البيع، المنتجات، نموذج المنتج، المبيعات، الماسح
├── widgets/product_actions.dart# بطاقة المنتج، إدخال المخزون، التحقق من السعر
└── utils/                      # تنسيق الأرقام والتواريخ، أدوات الباركود
```
